# Histórico de desenvolvimento do ConectAgro

Este documento descreve a evolução do projeto e as mudanças e resultados obtidos após cada reunião/aula

## Aula - 19/08 (Inicialização do ambiente)

Em aulas passadas, havíamos tomado decisões com respeito a qual stack utilizar (React + FastAPI), a abordagem que o repositório iria seguir, possíveis responsabilidades de cada um dos membros e o que deveria ser estudado.

Destas decisões, tivemos uma base sólida para desenvolver o ambiente que consistiu de uma mescla de tecnologias e configurações de projetos anteriores dos quais os membros do grupo já participaram, acelerando o desenvolvimento inicial.
